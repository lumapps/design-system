**Tooltips display information when users hover or focus an element.**\
They are positioned using anchor elements.

## Placement

Tooltips are positioned at the bottom of the target by default.
Tooltips' position can be forced to one of these options: `top`, `right`, `bottom`, or `left`.
If there is not enough space to correctly display the tooltip, tooltip will be displayed at the best position.

### Accessibility concerns

Tooltips implement the [WAI-ARIA tooltip role](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) and are **only accessible via mouse hover or keyboard focus**. As such it should generally be used **only on focusable element**.

Tooltip messages should be concise, directly describing the element that triggered it and should not contain essential information.

By default, the tooltip is linked to the anchor via `aria-describedby`, meaning as a description of the anchor element. Use `ariaLinkMode="aria-labelledby"` to link to the anchor via `aria-labelledby` and thus using the tooltip as the label for the anchor.

Use `closeMode="hide"` to render the tooltip hidden when not activated and keep to more accessible to screen readers. By default `closeMode="unmount"` is used and the tooltip only render when activated.

Consider using the [Popover](/product/components/popover/#accessibility-concerns) as a disclosure element to show longer or richer messages.

## Truncated text

Prefer to let long texts wrap on multiple lines.
When the layout cannot wrap (for example, in a button or a navigation item), truncate the text and show its full value in a tooltip, only when it overflows.

Use `useOverflowTooltipLabel` (from `@lumx/react/utils` or `@lumx/vue/utils`): set `labelRef` on the truncated element and give `tooltipLabel` to the tooltip `label`.
The tooltip measures the text when it opens, so it stays correct after a resize.
