## States

Side navigation items have two states: _resting_, and _selected_.

<DemoBlock demo={{ react: DemoStates }} />

Two props produce the selected style. Use `isCurrentPage` for a link to the page you are on. Use `isSelected` for a selection that is not a page, or for an item that is not a link.

`isCurrentPage` sets `aria-current="page"` on the link. A screen reader then announces the item as the current page. The style comes from that attribute, so these two other ways give the same result:

-   Set `aria-current="page"` with the `linkProps` prop.
-   Use a router link component in the `linkAs` prop that marks the active route by itself, such as a React Router `NavLink`.

`isSelected` sets a modifier class only. It gives no information to a screen reader.

## Nested items

### Accessibility concerns

Side navigations use standard HTML nested unordered list. Consider wrapping the `SideNavigation` in a `<nav>` to mark the navigation region.

Side navigation items default to a list item with a button inside. Adding a `linkProps.href` or `linkAs` prop will transform it into a link (or use the custom link component you provided).

Side navigation items with children use the [ARIA disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) using the `isOpen` prop to control the expand/close state that should be toggled when the `onClick` is called. Combining `linkProps.href` and `onActionClick` will split the toggle button and the link.
